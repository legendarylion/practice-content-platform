# ICP/Questionnaire to Zocdoc Field Map

Zocdoc does not publish character limits for its text fields (confirmed on
the Michael Lydon 2026-06-26 engagement - see `_local/` and `README.md` in
this folder). Counts below are for scannability, not enforcement; there is
no `limits.json` here for that reason. **Confirm directly in the provider
dashboard if a hard limit ever needs verifying.**

| Zocdoc field | Observed comfortable length | Primary ICP/questionnaire source |
|---|---|---|
| "Professional Statement" (About) | ~700-750 chars worked cleanly | ICP Ideal Client + Differentiation, same source PT's personal statement draws from. |
| "What should a new client know about working with you?" | ~500-550 chars | ICP Voice + intake 3.2 reassurance language. |
| "What is your typical process for working with clients?" | short, direct | Intake 3.1 (intake process) + 2.5 approach in plain language. |
| Visit Reasons | tags, not prose | Intake 2.2 issues known for - widen rather than narrow; this is Zocdoc's search-matching field. |
| Reviews | N/A - not copy | Not a copy field, but confirmed on the Lydon engagement as "Zocdoc's single biggest lever" - flag a review-generation habit on the punch list for every Zocdoc engagement. |

## Compliance note

The Lydon engagement flagged two advertising-compliance issues in the
narrative fields - Zocdoc (like PT) has content review, so avoid outcome
guarantees and superlative claims regardless of the absence of a hard
character cap.
